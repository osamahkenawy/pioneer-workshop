STEP 2 — Fix DNF Repositories  ⚠️  REQUIRED — server has no repos enabled
================================================================================

  The server shows:
    "Error: There are no enabled repositories in /etc/yum.repos.d/"
  This means RHEL is NOT registered with Red Hat Subscription Manager.
  Fix this by adding CentOS Stream 9 compatible repos (no subscription needed):

  -- 2a. Create a working repo file using CentOS Stream 9 mirrors:

    sudo tee /etc/yum.repos.d/centos-stream9.repo > /dev/null << 'EOF'
    [baseos]
    name=CentOS Stream 9 - BaseOS
    baseurl=https://mirror.stream.centos.org/9-stream/BaseOS/x86_64/os/
    gpgcheck=1
    enabled=1
    gpgkey=https://www.centos.org/keys/RPM-GPG-KEY-CentOS-Official

    [appstream]
    name=CentOS Stream 9 - AppStream
    baseurl=https://mirror.stream.centos.org/9-stream/AppStream/x86_64/os/
    gpgcheck=1
    enabled=1
    gpgkey=https://www.centos.org/keys/RPM-GPG-KEY-CentOS-Official

    [extras]
    name=CentOS Stream 9 - Extras
    baseurl=https://mirror.stream.centos.org/9-stream/extras/x86_64/extras/
    gpgcheck=1
    enabled=1
    gpgkey=https://www.centos.org/keys/RPM-GPG-KEY-CentOS-Official
    EOF

  -- 2b. Import the CentOS GPG key:

    sudo rpm --import https://www.centos.org/keys/RPM-GPG-KEY-CentOS-Official

  -- 2c. Verify repos are working:

    sudo dnf repolist
    sudo dnf makecache

    Expected: you should see baseos, appstream, extras listed with package counts.

  NOTE: If the server is on an internal network with no internet access, ask
        your sysadmin for the internal mirror URL and replace the baseurl above.

STEP 7 — Install MySQL 8
================================================================================

  -- 7a. Add the MySQL 8 Community repo (choose based on your RHEL version):

  For RHEL 9:
    sudo dnf install -y https://dev.mysql.com/get/mysql80-community-release-el9-1.noarch.rpm

  For RHEL 8:
    sudo dnf install -y https://dev.mysql.com/get/mysql80-community-release-el8-1.noarch.rpm

  -- 7b. Install MySQL server:

    sudo dnf install -y mysql-community-server

  -- 7c. Start and enable MySQL:

    sudo systemctl enable mysqld
    sudo systemctl start mysqld

  -- 7d. Get the auto-generated temporary root password:

    sudo grep 'temporary password' /var/log/mysqld.log

    (Copy the password shown at the end of that line — you will need it next)

  -- 7e. Set a new root password (replace TMP_PASS with the password from 7d):

    mysql -u root -p'TMP_PASS' --connect-expired-password -e \
      "ALTER USER 'root'@'localhost' IDENTIFIED BY 'Root@12345'; FLUSH PRIVILEGES;"

    NOTE: MySQL 8 requires a strong password (uppercase + number + symbol).
          Password used: Root@12345
          Change it to something stronger in production.

  -- 7f. Test the new password:

    mysql -u root -p'Root@12345' -e "SHOW DATABASES;"

STEP 11 — Configure Nginx
================================================================================

  -- 11a. Create the Nginx config file:

    sudo tee /etc/nginx/conf.d/car-workshop.conf > /dev/null << 'EOF'
    server {
        listen 80;
        server_name 10.10.241.84 _;

        root /var/www/car-workshop/frontend;
        index index.html;

        location / {
            try_files $uri $uri/ /index.html;
        }

        location /api/ {
            proxy_pass         http://127.0.0.1:4000/api/;
            proxy_http_version 1.1;
            proxy_set_header   Upgrade           $http_upgrade;
            proxy_set_header   Connection        'upgrade';
            proxy_set_header   Host              $host;
            proxy_set_header   X-Real-IP         $remote_addr;
            proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
            proxy_set_header   X-Forwarded-Proto $scheme;
            proxy_read_timeout 120s;
        }

        location /socket.io/ {
            proxy_pass         http://127.0.0.1:4000/socket.io/;
            proxy_http_version 1.1;
            proxy_set_header   Upgrade    $http_upgrade;
            proxy_set_header   Connection "upgrade";
            proxy_set_header   Host       $host;
        }

        location /uploads/ {
            proxy_pass       http://127.0.0.1:4000/uploads/;
            proxy_set_header Host $host;
        }

        client_max_body_size 50M;
        gzip on;
        gzip_types text/plain text/css application/json application/javascript
                   text/xml application/xml image/svg+xml;
    }
    EOF

  -- 11b. Allow SELinux to let Nginx connect to the backend (port 4000):

    sudo setsebool -P httpd_can_network_connect 1

  -- 11c. Test and reload Nginx:

    sudo nginx -t
    sudo systemctl reload nginx

  Expected: nginx configuration file test is successful

================================================================================
TROUBLESHOOTING
================================================================================

  Backend not starting:
    pm2 logs car-workshop-backend --lines 50

  Nginx not serving:
    sudo nginx -t
    sudo tail -50 /var/log/nginx/error.log

  SELinux blocking Nginx:
    sudo ausearch -c nginx | tail -20
    sudo setsebool -P httpd_can_network_connect 1

  MySQL connection refused:
    sudo systemctl status mysqld
    mysql -u root -p'Root@12345' -e "SHOW DATABASES;"

  Port not open:
    sudo firewall-cmd --list-all
    sudo ss -tlnp | grep -E '80|443|4000'
