PART 1 — ONE-TIME SERVER SETUP  (run only the first time)
================================================================================

-- 1.0  Get root / elevated access ------------------------------------------

  OPTION A — Drop into a root shell (easiest, recommended):
    sudo -i
    # You are now root. Prompt changes from $ to #
    # Type  exit  to go back to your normal user

  OPTION B — Run a single command as root:
    sudo <command>
    e.g.  sudo dnf install -y nginx

  OPTION C — Switch to root using su (needs root password, often disabled):
    su -
    # Enter root password when prompted

  CHECK — See what sudo rights you have:
    sudo -l
    # Look for (ALL) ALL or (ALL : ALL) ALL — means full root access

  IF SUDO IS DENIED:
    Your account may not be in the wheel group (RHEL equivalent of sudoers).
    Ask your sysadmin to run:
      usermod -aG wheel osamah.kenawy
    Then log out and back in via CyberArk for the change to take effect.

  NOTE: All commands in this guide that start with "sudo" should be run
        while logged in as osamah.kenawy. Do NOT run everything as root
        permanently — use sudo per-command or sudo -i for a root session
        and exit when done.


-- 1.1  Check OS and current user ------------------------------------------

  cat /etc/redhat-release
  whoami
  sudo whoami          # should print: root

  If sudo asks for a password, enter your CyberArk-managed password.
  If you do not have sudo, ask the sysadmin to add you to /etc/sudoers.


-- 1.2  Update system packages -----------------------------------------------

  sudo dnf update -y


-- 1.3  Install Git -----------------------------------------------------------

  sudo dnf install -y git
  git --version


-- 1.4  Install Node.js 20 (via NodeSource) ----------------------------------

  curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
  sudo dnf install -y nodejs
  node -v      # should print v20.x.x
  npm -v


-- 1.5  Install PM2 globally -------------------------------------------------

  sudo npm install -g pm2
  pm2 -v


-- 1.6  Install Nginx --------------------------------------------------------

  sudo dnf install -y nginx
  sudo systemctl enable nginx
  sudo systemctl start nginx
  sudo systemctl status nginx


-- 1.7  Install MySQL 8 ------------------------------------------------------

  Step A — Add the MySQL 8 repo:
    sudo dnf install -y https://dev.mysql.com/get/mysql80-community-release-el9-1.noarch.rpm
    sudo dnf install -y mysql-community-server

  Step B — Start and enable MySQL:
    sudo systemctl enable mysqld
    sudo systemctl start mysqld

  Step C — Get the temporary root password printed in the log:
    sudo grep 'temporary password' /var/log/mysqld.log

  Step D — Secure MySQL and set a new root password:
    sudo mysql_secure_installation
    (Follow prompts: change root password, remove anonymous users,
     disallow remote root login, remove test DB, reload privilege tables)

  Step E — Verify login:
    mysql -u root -p
    EXIT;

  NOTE: Replace DB_PASSWORD in .env with the password you set here.


-- 1.8  Create app directories -----------------------------------------------

  sudo mkdir -p /var/www/car-workshop/backend
  sudo mkdir -p /var/www/car-workshop/frontend
  sudo chown -R osamah.kenawy:osamah.kenawy /var/www/car-workshop


-- 1.9  Configure firewall ---------------------------------------------------

  sudo firewall-cmd --permanent --add-service=http
  sudo firewall-cmd --permanent --add-service=https
  sudo firewall-cmd --permanent --add-port=4000/tcp   # optional direct access
  sudo firewall-cmd --reload
  sudo firewall-cmd --list-all


-- 1.10  Configure SELinux for Nginx reverse proxy ---------------------------

  SELinux on RHEL blocks Nginx from connecting to backend by default.
  Run this to allow it:

  sudo setsebool -P httpd_can_network_connect 1

  Also allow Nginx to serve the /var/www directory:
    sudo chcon -Rt httpd_sys_content_t /var/www/car-workshop/frontend

  If you hit SELinux denials later, check:
    sudo ausearch -c nginx | tail -30
    sudo tail -50 /var/log/audit/audit.log | grep denied


-- 1.11  Configure Nginx ------------------------------------------------------

  Create the config file:

    sudo tee /etc/nginx/conf.d/car-workshop.conf > /dev/null << 'EOF'
    server {
        listen 80;
        server_name 10.10.241.84;

        # Frontend SPA
        root /var/www/car-workshop/frontend;
        index index.html;

        location / {
            try_files $uri $uri/ /index.html;
        }

        # Backend API
        location /api/ {
            proxy_pass         http://127.0.0.1:4000/api/;
            proxy_http_version 1.1;
            proxy_set_header   Upgrade           $http_upgrade;
            proxy_set_header   Connection        'upgrade';
            proxy_set_header   Host              $host;
            proxy_set_header   X-Real-IP         $remote_addr;
            proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
            proxy_set_header   X-Forwarded-Proto $scheme;
            proxy_read_timeout 120s;
        }

        # Socket.IO
        location /socket.io/ {
            proxy_pass         http://127.0.0.1:4000/socket.io/;
            proxy_http_version 1.1;
            proxy_set_header   Upgrade    $http_upgrade;
            proxy_set_header   Connection "upgrade";
            proxy_set_header   Host       $host;
        }

        # Uploaded files
        location /uploads/ {
            proxy_pass       http://127.0.0.1:4000/uploads/;
            proxy_set_header Host $host;
        }

        client_max_body_size 50M;
        gzip on;
        gzip_types text/plain text/css application/json application/javascript text/xml application/xml image/svg+xml;
    }
    EOF

  Test and reload:
    sudo nginx -t
    sudo systemctl reload nginx

PART 6 — TROUBLESHOOTING
================================================================================

PROBLEM: curl http://127.0.0.1:4000/health returns "Connection refused"
  → Backend is not running.
    pm2 logs car-workshop-backend --lines 100
    Check for missing .env values or DB connection errors.

PROBLEM: Nginx returns 502 Bad Gateway
  → Backend is down or not listening on port 4000.
    pm2 status
    pm2 restart car-workshop-backend

PROBLEM: Nginx returns 403 Forbidden on frontend
  → SELinux is blocking file access.
    sudo chcon -Rt httpd_sys_content_t /var/www/car-workshop/frontend
    sudo setsebool -P httpd_can_network_connect 1

PROBLEM: MySQL "Access denied for user 'root'"
  → Wrong password in .env.
    Verify: mysql -u root -p  (enter password manually)
    Then update DB_PASSWORD in .env and restart:  pm2 restart car-workshop-backend

PROBLEM: "Cannot find package 'swagger-ui-express'"
  → Run npm install in the backend directory.
    cd /var/www/car-workshop/backend && npm install --omit=dev

PROBLEM: PM2 process is not running after server reboot
  → PM2 startup was not saved correctly.
    pm2 startup systemd -u osamah.kenawy --hp /home/osamah.kenawy
    Run the printed command, then: pm2 save

PROBLEM: Port 80 not accessible from outside
  → Firewall is blocking it.
    sudo firewall-cmd --list-all
    sudo firewall-cmd --permanent --add-service=http && sudo firewall-cmd --reload
    Also check if the organisation's network firewall allows port 80 to 10.10.241.84.

PROBLEM: Frontend loads but API calls fail (CORS or 404)
  → Check VITE_API_URL is set correctly in .env.production before building.
  → Check Nginx proxy_pass for /api/ is correct.
    sudo nginx -t
    sudo tail -30 /var/log/nginx/error.log
